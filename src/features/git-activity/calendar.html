汇总与统计说明

仅显示当月有提交的人员；点击日期查看提交详情。△ 表示包含大批量变更。

日期采用提交入库时间（committer date），统一换算为北京时间。最近一天仅统计到快照时间；日历不是考勤记录。

统计所选本地仓库及其本地可达分支、标签（可能包含未推送记录），远程地址以下载的仓库历史为准。无法访问或同步失败时保留上一份报告。浅克隆或未联网同步会另行提示。

排除合并提交；以归并身份与 SHA 去重，并对文件变更统计一致的候选提交比较稳定 patch-id。全部仓库跨仓库去重，单仓库仅仓库内去重。重复补丁归入首次保留记录的日期。不能识别所有语义相同的迁移。

代码行数为受支持源码文件的新增和删除，排除依赖、构建目录及压缩产物；不等于工时或原创代码量。单次变更超过 10,000 行或 100 个源文件视为大批量变更。二进制不计代码行数。

人员按邮箱区分，按配置合并与排除；原始作者和邮箱保留在详情。低行数提示只应用于工作日，休息日和节假日免判定；尚未核对节假日的年份也免判定。数量不能单独判断工作质量或工资。
