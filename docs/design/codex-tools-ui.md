# Codex Tools 界面规范

适用：Codex / Claude 账号、分析、API 反代、设置、授权与确认弹窗。

依据 Apple HIG 的视觉层级、稳定导航、相关操作分组、克制强调和自适应原则。本文尺寸是 Codex Tools 针对鼠标与键盘桌面应用制定的 CSS px 规范，不是 Apple 强制尺寸。当前实现为 Tauri WebView；不声称实现原生 AppKit 控件或 Liquid Glass。

## 框架

- 全局导航使用左侧栏：208px；中等窗口 176px；780px 以下为 64px 图标栏，保留可访问名称与悬停提示。
- 品牌切换固定在侧栏顶部，Codex / Claude 共用一套布局。只展示当前平台已支持的功能。
- 设置放在侧栏底部；当前页以背景、文字颜色及 aria-current 同时表示。
- 顶部工具栏 64px，显示平台、当前页与全局工具。空白区域拖动窗口，双击切换最大化。
- macOS 侧栏顶部保留 48px 系统窗口控制区。
- 页面边距 24px；窄窗口 16px。账号列表利用可用宽度，分析页最大 1440px，设置页最大 880px（含左右边距），代理页最大 1240px。详情从右侧按需打开，禁止堆到列表底部。

## 尺寸、文字与表面

| 类别 | 规范 |
| --- | --- |
| 间距 | 4 / 8 / 12 / 16 / 24 / 32px；相关项间距小于分组间距 |
| 字体 | 系统字体，macOS 优先 SF；代码与 Token 使用等宽字体 |
| 页面标题 | 22px / 600 |
| 工具栏、区域标题 | 14px / 600 |
| 正文、表单 | 13px / 400–550 |
| 控件文字 | 12px / 500–550 |
| 辅助数据 | 11–12px；必须可读，不使用极浅灰 |
| 数值 | 等宽数字，摘要 22px / 600 |
| 普通控件 | 高 32px；分段组内 28px；同排同高 |
| 圆角 | 控件 6px，内容面板 10px，弹窗 12px |
| 分隔 | 1px 语义边框；避免每个元素单独套卡片 |
| 阴影 | 主要用于弹窗浮层；普通按钮、列表不使用厚阴影或高光渐变 |

## 颜色与动作

- 中性色构成内容、侧栏、表面、边框和辅助文字，浅色和深色分别定义语义 Token。
- 主要动作使用中性实心色，导航和页签使用灰阶选中态。蓝色用于焦点与账号状态，图表使用单一青色。各平台 Logo 保留自己的品牌色。
- 每个任务区域优先一个主要动作；其他动作使用普通按钮或菜单。相邻按钮靠样式区分优先级，不靠大小。
- 成功、警告、错误颜色必须搭配文字说明，不独靠颜色表达。
- 危险动作显式标识，现有确认流程保留。刷新和主题图标保留可访问名称。
- 按钮提供悬停、按下、焦点、禁用状态；禁用保持可辨识。键盘焦点使用 2px 强调色轮廓。

## 页面模式

- 账号：工具栏将搜索/筛选放在左侧，添加等相关动作在右侧成组；每行固定身份、用量、状态与操作区域。
- Claude：概览、空状态、账号行使用相同色彩和控件尺寸；额度未知显示“—”，刷新失败保留缓存并说明。
- 分析：同一网格放置摘要；图表与列表按信息重要性排列；相同类型数据对齐。
- API 反代：服务状态、服务操作优先，凭据和高级配置分组展示。
- 设置：使用标题加分组行，短控件与标签同排；路径与预览使用明确的 stacked 结构，占完整行宽，禁止塞进短控件栏。
- 授权：统一标题与关闭位置，授权方式使用左侧方法列表，将推荐路径与其他导入方式分组；窄窗口重排到表单顶部，主操作在底部右侧。
- 空状态：说明当前没有内容及下一步；搜索无结果与无账号分别表达。
- 加载/错误：使用现有真实状态与重试入口，不用装饰性假数据。

## 实现与验收

规范入口：`src/styles/hig/index.css`，拆分为 tokens、shell、controls、pages。新功能优先复用语义 Token；不再为单页另建一套品牌按钮。

验收覆盖：Codex 与 Claude、空列表与有数据、账号/分析/反代/设置、授权弹窗、浅/深主题、常规和窄窗口、键盘可访问名称、减少动态效果。界面改造不改变账号授权、续期、工作区保留和服务配置逻辑。

## CC Switch 风格适配

参考 [CC Switch 设计系统](https://github.com/farion1231/cc-switch/blob/main/docs/design-system.html) 和 [用量页结构](https://github.com/farion1231/cc-switch/tree/main/src/components/usage)，采用相同的视觉秩序，在 Codex Tools 内独立实现。

- 以中性色组织界面。描边区分面板，阴影只表达浮层；不要给每个数字和动作加卡片。
- 主要按钮、普通描边按钮、轻量图标动作三级；分段选项使用灰底轨道，内容页签使用下划线。保留语义状态及键盘焦点。
- 全部原生文本输入、密码输入、文本域、下拉触发器共享边框、字号、间距和焦点规则。搜索框只有一层边框。32px 为标准行高，28px 只用于分段选项内部。
- 样式必须覆盖 `document.body` 下的弹窗、菜单和其他 Portal，不能仅作用于页面容器。原生下拉菜单本身遵循操作系统绘制。
- 账号详情默认关闭。点击名称、行或查看详情打开；切换账号、代理开关、更多菜单独立操作。Esc / 关闭返回原焦点。账号工作区内容宽度达到 1120px 时并排（详情 360px，间距 16px，列表至少 744px）；不足时使用带背景遮罩和焦点限制的右侧面板，工作区低于 560px 时详情占满内容区；列表与详情分别滚动。
- 账号数值保持紧凑格式和完整单位，禁止省略号截断 Token 数值。列表按实际容器宽度重排。
- 分析页为指标与图表合并面板，下方以会话 / 项目 / 活跃时段 / Prompt / 预算组织内容。指标切换和星期筛选仅改变图表，不伪造实时请求或每日趋势。当前图表是扫描记录按星期、小时累计的分布。
- 图表随容器重算绘图区，保持坐标字号，窄窗口减少刻度；表格在自身容器内横向滚动。

新增样式模块：`fields.css`（全局控件契约）、`inspector.css`（账号详情）、`analytics.css`（分析页）。不新增图表运行库；小时数据在内存聚合，窗口尺寸变化仅重新布局图表。

## 信息精简

统计首页只保留累计估算费用、累计 Token、会话数，图表在费用和 Token 之间切换。数据范围与图表筛选范围直接可见，附加口径放到悬停提示；不把记录条数包装成请求数。账号概览使用紧凑状态行，Token 汇总用轻量信息条，避免摘要和辅助数字抢占账号列表的视觉层级。

## API 反代

本地服务在用量、配置及公网标签顶部展示，远程服务器标签隐藏本地服务区，状态、端口与启动操作保持同一视觉层级；Base URL 独立一行，客户端绑定收进可展开区域。下方使用用量、配置、远程服务器、公网访问四个标签。标签切换保留表单状态，服务错误始终可见。配置内容使用分组行和细分隔线，避免多层卡片与状态胶囊；图表空状态去除装饰光球。窄窗口允许操作行与状态换行，沿用全局控件和深色主题规则。对应样式模块为 `src/styles/hig/proxy.css`。

反代页进一步统一为单一连续工作面板，最大外宽 1240px，内容边距 24px。服务标题和启停操作组成固定页头；端口、默认启动与连接地址在宽面板并排。响应式以 `proxy-page` 容器宽度为准：760px 以下连接设置与服务器导航整组纵向排列，560px 以下页头操作、密钥信息和双列表单统一重排。禁止复用旧的窗口断点将单个按钮拉满。配置使用连续字段行，操作固定在行尾；创建密钥使用完整表单行。结构与表单样式分别维护在 `proxy.css` 和 `proxy-forms.css`。


## 共用结构与交互契约

- 页面由 PageFrame 的 list / analysis / service / settings 四种模式管理宽度；PageHeader 管理标题和动作，SectionGroup 管理任务分组。不得用页面专属巨型按钮补齐布局。
- AccountListRow、Inspector、ActionMenu 同时用于 Codex 和 Claude。列表优先身份、额度、状态与切换；本地 Token、速度和余额在详情查看，避免每行堆积次级数字。
- UtilityDialog 统一标题、关闭、内容和动作区，负责焦点限制、Esc 关闭和返回触发控件。授权弹窗和删除确认共用此契约。
- EditorMultiSelect 使用原生 select，键盘方向键、输入定位与菜单边缘处理交由系统。触发器仍使用同一套字段样式。
- 会话每页 25 条，项目每页 10 条；分页同时展示当前区间与总数。过滤结果改变后回到第一页，禁止仅裁掉数据却展示完整总数。
- 复制、预算保存的成功与失败使用 FeedbackHost。输入错误在字段附近显示，并关联 aria-invalid / aria-describedby。会话删除使用确认弹窗，不再要求限时二次点击。
- 代理配置分为路由策略、密钥、运行诊断。公网访问使用安装 / 配置 / 运行进度，设置与状态拆为独立组件；远程服务器保留主从导航与按需展开配置、日志。
- 设置的简单开关行在窄窗口仍保持标签左、开关右；复杂字段和预览才纵向排列。分组间距 24px，不能同时叠加 gap 和外边距。
- 中文、英文、日文、韩文、俄文覆盖共用控件、Claude 授权与分析摘要。窄侧栏图标保留显式 aria-label。

结构样式位于 foundation.css、account-layout.css、form-layout.css；业务特有样式仍保留在对应模块。响应式重排以容器可用宽度为依据，禁止通过缩小字号隐藏内容拥挤。

## 布局与动态效果补充

- AccountsWorkspace 负责摘要、列表和详情的共同布局。摘要跨工作区，列表与详情顶边对齐；账号行仅在列表容器不足 720px 时双行，不与窗口媒体查询交叉决定。
- Inspector 在并排模式为 region，在覆盖模式为 modal dialog；覆盖模式 Tab 约束在面板内，Escape 关闭并恢复账号触发器焦点。嵌套确认框优先接管焦点。
- Switch 是所有页面唯一的开关实现：32×20px 轨道，28px 高点击区，16px 白色滑块；包含键盘焦点和禁用态。
- SettingsRow 以 inline / stacked 区分短控件和整行内容；图标预览使用至少 100px 的网格单元。真实尺寸的图片参与预览验收，不能只用空占位符。
- SearchField 统一搜索图标、输入、清空按钮；Escape 优先清空搜索，清空后保留输入焦点。
- 统计摘要都是只读数据；费用/Token 切换移到图表工具栏。小时分布明确标为历史记录按小时汇总，不表示每日趋势。
- 账号管理、到期信息和历史记录按需展开；身份显示在详情头部，避免重复标题。设置页顶部标识 Codex Tools，Codex 专属设置分组带 Codex 前缀。
- 页面、列表、表格和大面积布局不做进入动画。弹窗、详情、菜单、提示仅做 120ms 透明度进入与退出；退出期间不可交互，完成后恢复焦点。开关保留滑块反馈，不增加缩放和位移效果。
- prefers-reduced-motion 关闭动画和过渡，直接完成退出。
- 弹窗统一标题区、可滚动内容区与底部操作区：普通宽 540px，授权及额度引导宽 780px，确认宽 440px；窄窗口保留 16px 边距。主要提交动作放在底部，取消为次要动作。
- 删除等低频危险操作收进更多菜单，确认弹窗再强调危险动作。保存期间显示忙碌状态；表单错误放在相关字段附近并关联辅助说明，短反馈支持手动关闭。
- 浏览器回归入口：scripts/ui-checks/coordination.mjs。检查工作区断点两侧、480–1920px、真实尺寸预览、键盘返回、图表操作、反代各标签和多语言布局。图形预览样本仅是 UI fixture，不代表当前账号真实额度。
