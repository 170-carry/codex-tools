# 桌面界面与模块边界

桌面界面统一使用原版布局。精简布局的账号表格、模态详情、页内分页、独立样式和布局选择器已移除。应用不再读取或写入布局偏好，已有的旧偏好不会改变启动界面。

## 页面结构

| 页面 | 当前结构 |
| --- | --- |
| 账号 | 四个账号汇总卡、常显搜索与筛选、账号列表、常驻详情面板 |
| 分析 | 统计与预算、项目、活跃时段、会话与 Prompt 分区 |
| API 反代 | 服务、用量、密钥与模型、远程服务器、公网访问分区 |
| 设置 | 通用、额度栏、账号切换、自动预热、关于五个分区 |

账号列表保留每行反代开关、重置卡数量、套餐变体和显式切换。详情保留别名编辑、会员时间、Token/TPS、账号顺序、重置卡确认与最近切换记录。查看账号或选择套餐不会隐式切换当前账号。

原版窗口默认 1586 × 992，最小尺寸 640 × 500。窄窗口将详情与列表纵向排列，列表与页面可独立滚动。保留明暗主题、系统时区和减少动画偏好。

## 模块划分

- `App.tsx`：组合导航、按需加载的页面和弹窗，使用唯一的原版界面。
- `components/classic/`：账号、顶部导航、分析标题/项目、代理和设置的原版呈现。
- `components/accounts/`：共享账号操作、重置卡、用量状态和导入/编辑弹窗。
- `components/analytics/`：预算、会话、活跃时段、Prompt、格式化与操作。
- `components/proxy/`：服务、密钥、模型、远程与公网访问组件，专用状态 hooks 和图表模块。
- `components/settings/`：设置分区、平台数据与保存逻辑。
- `components/workspace/`：页面适配、异步页面入口、通用弹窗与共享图标。
- `styles/classic/`：原版布局、账号详情、菜单、弹窗与响应式规则。

业务逻辑继续复用控制器及后端命令。布局清理不改动鉴权、账号切换、反代路由、预热与重置卡消费规则。

## 快捷键与验证

| 快捷键 | 操作 |
| --- | --- |
| ⌘1 / ⌘2 / ⌘3 / ⌘4 | 账号 / 分析 / API 反代 / 设置 |
| ⌘, | 设置 |
| ⌘F | 聚焦常显账号搜索 |
| ⌘N | 添加账号 |
| ⌘R | 刷新当前页面 |
| Escape | 关闭菜单或弹窗并恢复焦点 |

Windows 与 Linux 使用 Ctrl。模态弹窗打开时不触发自定义全局快捷键。

静态检查覆盖账号排序、反代开关、未知/零张重置卡、所有页面分区与多语言渲染。浏览器回归覆盖旧布局偏好兼容、账号操作、确认取消、快捷键、导航延迟加载、明暗主题与小窗口。模拟后端测试不代替原生系统验收。
