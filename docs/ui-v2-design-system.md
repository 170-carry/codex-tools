# Codex Tools 界面布局

## 原版默认与布局切换（2026-10-04）

默认使用原版布局，精简布局为可选项。新安装和从未保存过布局偏好的已有用户，启动时均进入原版。

- 窗口右上角的布局选择器，以及「设置 → 通用 → 界面布局」，均提供「原版布局 / 精简布局」。
- 选择立即生效，使用独立的 `codex-tools-layout` 本地偏好保存；重启后恢复用户选择，不影响账号、授权、主题或其他设置。无效偏好回退到原版。
- 原版账号页恢复统计卡片、常显搜索筛选、Token 汇总、左侧账号列表和右侧详情；分析、反代、设置恢复分区常显。
- 原版视图复用当前控制器和账号排序逻辑，保留 3.0.1 的反代参与开关、列表中的重置卡数量，以及 API 账号编辑和认证期间的操作锁。
- 原版使用已存档的卡片、颜色与排版样式；所有精简版覆盖规则限定在 `data-layout="compact"`，避免全局变量或同名控件污染原版。
- 初始窗口尺寸恢复为原版的 1586 × 992，仍可自由缩放。切换布局不会强制调整当前窗口大小。
- 原版呈现组件位于 `components/classic/`，布局偏好和选择器位于 `components/layout/`、`hooks/useAppLayout.ts` 与 `utils/layoutPreference.ts`，不复制后端业务逻辑。

本轮验证：37 项 Node 单元测试、43 项既有页面静态渲染检查、30 项双布局静态渲染检查通过；前端与测试源类型检查、ESLint、macOS 独立预览应用打包通过。覆盖默认原版、保存与重新读取、异常偏好回退、两套页面结构、样式隔离和既有账号操作入口。浏览器实际点击、重启和截图验收仍未执行；静态检查不代替这部分验证。

以下为精简布局的设计说明与历史验证记录。

## 精简布局

主界面围绕账号列表和剩余额度组织，所有业务功能继续保留。一级导航使用标题栏紧凑分段控件，操作使用工具栏与菜单，低频详情按需展开。主界面采用无卡片边框的平面列表，不设置常驻侧栏。

## 页面结构

| 区域 | 内容 | 呈现方式 |
| --- | --- | --- |
| 导航 | 账号、分析、API 反代、设置 | 标题栏分段控件与右侧设置按钮；点击一次即可切换 |
| 当前账号 | 当前身份、套餐、两种剩余额度、重置时间 | 列表中仅标识 `isCurrent` 对应行，不设置重复摘要 |
| 账号列表 | 账号与套餐/重置卡、5h 剩余、每周剩余、反代、操作 | 五列紧凑表格；反代开关常显，列表单独滚动 |
| 窗口工具栏 | 页面切换、搜索、刷新、设置、添加 | 顶部单行；搜索与筛选按需展开，支持 ⌘F |
| 页底状态栏 | 总数、最近成功更新时间、系统本地时区、更多 | 账号状态统计、智能切换、全部导出与分析入口置于“更多”菜单 |
| Token 使用量 | 24H、3D、7D、30D | 集中在分析页，保留全部时间窗口，刷新分析时一起更新 |
| 账号详情 | 改名、会员有效期、重置卡、切换记录、账号操作 | 模态检查器，按需打开 |
| 分析 | 预算、项目、热力图、会话、提示、CSV/JSON 导出 | 单行统计、可展开预算、项目/会话/活跃时段/Prompt 四个页内分组；项目使用表格 |
| API 反代 | 本地控制、用量、密钥、模型、远程部署、公网隧道 | 服务/密钥与模型/用量/远程服务器/公网访问五个页内分组；密钥权限与调用记录按需展开 |
| 设置 | 外观、状态栏、预热、切换行为、更新 | 通用/额度栏/账号切换/自动预热/关于五个页内分组，设置项按行对齐 |

查看账号详情和选择套餐变体不会隐式切换当前账号。只有明确点击切换或智能切换才调用已有切换流程。

## 视觉规则

- 使用系统字体和中性灰，避免粗重标题、金色套餐徽章、大头像、装饰背景和重复卡片。
- 蓝色强调主要操作；额度不足与错误使用语义颜色。未知额度显示 `--`，不生成虚假的百分比。
- 当前账号使用极淡的中性色底与左侧 2 像素短线标识，不使用整行蓝色填充；明暗主题都保持文字与额度的原始颜色。
- PRO、PLUS、FREE 使用淡蓝、淡紫和中性灰标签。重置卡在套餐标签右侧用小图标与数量展示，直接读取服务端可用数量；0 明确显示，未知显示 —，不从卡片明细长度推算数量。
- 每行的“反代”列常显参与开关，可直接用鼠标或键盘切换；保存期间禁用，失败回退已有状态。更多菜单不再重复提供此开关。
- 添加账号采用固定标题栏、紧凑方式列表与单份说明；手动 OAuth 回调按需展开，API Key 默认遮挡，弹窗内保持键盘焦点循环。
- 同一进度条始终表示剩余额度。紧凑表格第一行对齐进度条与百分比，第二行常显完整 `YYYY/MM/DD HH:mm` 重置时间；具体重置时刻的系统时区和 UTC 偏移通过提示与无障碍名称提供。未知时间显示 —。
- 保留缓存失败提示。列表用短提示减少占用，完整原因与缓存时间通过提示和检查器查看。
- 玻璃与模糊仅用于工具栏和菜单；业务内容采用清晰的实色表面。
- macOS 原生窗口按钮由 Tauri/系统提供，不在 HTML 中绘制红黄绿按钮。
- 精简布局仍支持 920 × 700 的紧凑窗口，最小窗口为 640 × 500；应用初始尺寸按上方原版默认规则设置。默认未保存主题时使用系统偏好，用户可切换并保存明暗主题。
- 支持减少动画与减少透明度的系统偏好。

这些规则参考 [Apple macOS 设计指南](https://developer.apple.com/design/human-interface-guidelines/designing-for-macos) 和 [AppKit 新设计说明](https://developer.apple.com/videos/play/wwdc2025/310/)。内容仍由 Tauri WebView/React 渲染，CSS 材质不等同于 AppKit 原生 Liquid Glass。

## 交互与模块边界

`App.tsx` 只组合导航、视图与弹窗。分析、反代和设置视图按需加载。

- `components/workspace/`：窗口导航、视图适配、页内分组、工具栏、操作菜单、通用弹窗与共享图标。
- `components/analytics/`：项目/会话表格、活跃时段、Prompt、预算、统计、格式化与会话操作。
- `components/proxy/`：服务/模型/密钥/远程/公网状态 hooks 与各分组；图表数据计算、坐标/插值、控件、绘图与指针交互独立。
- `components/settings/`：通用、额度栏、切换行为、预热、关于；平台数据与设置操作集中在专用 hook。
- `components/accounts/`：账号行、套餐标签、额度与重置时间、列表状态栏与菜单、检查器、重置卡、Token 摘要。
- `utils/quotaTime.ts`：将服务端 Unix 时间转为系统本地完整日期、时间与该时刻的 UTC 偏移。
- `hooks/useAccountsWorkspace.ts`：搜索、筛选、套餐选择、查看详情与展示层切换记录。
- `hooks/useAnchoredMenu.ts`：菜单定位、视口约束、键盘导航与焦点恢复。
- `hooks/useAppNavigation.ts`：键盘快捷键、原生应用菜单事件与既有刷新生命周期。
- `styles/native/`：颜色、窗口、控件、账号、检查器、页面与响应式规则。

保留现有控制器及后端业务操作、授权锁、预热限制和设置保存流程。

页内分组采用 `tablist` / `tab` / `tabpanel`，支持左右方向键、Home/End 与对应焦点移动。非活动面板使用 `hidden`，内容保持挂载，因此页内切换不会清空未提交的密钥名称、服务器配置、会话搜索或预算草稿。当前页之外的分析/反代/设置继续按需加载。

模型选择、删除确认与更新弹窗共用 `UtilityDialog`：固定标题、内容独立滚动、底部动作、Escape/遮罩关闭、焦点限制与恢复。删除/安装进行中禁止意外关闭。全局快捷键同时识别 `dialog` 与 `alertdialog`。添加账号沿用独立导入框架，首次额度配置统一为紧凑灰底表单样式。

| 快捷键 | 操作 |
| --- | --- |
| ⌘1 / ⌘2 / ⌘3 / ⌘4 | 账号 / 分析 / 反代 / 设置 |
| ⌘, | 设置 |
| ⌘F | 聚焦账号搜索 |
| ⌘N | 添加账号 |
| ⌘R | 刷新当前页面 |
| Escape | 关闭菜单/检查器并恢复焦点 |
| ↑ / ↓ / Home / End | 在账号菜单中选择操作 |

Windows 与 Linux 使用 Ctrl 作为对应修饰键。模态弹窗打开时不触发这些自定义全局快捷键。
