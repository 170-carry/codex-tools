验证使用人工账号、令牌、项目、SQLite 数据库和会话文件。未安装应用、执行真实账号切换或修改真实项目数据。

## 覆盖场景

- 默认开启、缺失字段的兼容读取及显式关闭值保留。
- 合成 A → B → C → A 的项目定义、项目 ID、路径和对话归属一致性。
- 目标独有项目、并行修改、删除、排序、对话移动、明确未分组和陈旧快照冲突。
- 未管理的悬空关联保留在所属账号；两账号和三账号往返时拒绝覆盖或重新激活有歧义的关联。
- SQLite 暂缺线程行仍保留已保存关系；缺失项目、根路径不一致、云绑定和未知数据库结构继续拒绝。
- 只读预览、DB+WAL 临时私有快照、无会话正文或源 SQLite 写入。
- 停止失败、原子写入中断、首次 journal 临时文件、凭据刷新向前恢复和外部修改保护。
- 恢复期间阻止普通初始化或写入；恢复成功后重新初始化模型、密钥界面与托盘入口。
- CLI 实际入口使用 24 个合成项目、81 条归属和 4 条明确未分组记录，另加入悬空关联及缺失线程行；成功预览、异常路由拒绝和云绑定拒绝均保持合成源文件与目录不变。

## 范围与限制

提交不更改版本号、依赖、应用标识、更新源、开机启动设置、应用数据路径或发布工作流。存储锁、代理共享模块清单和恢复门控是保留事务的必要集成。

原生 Windows 生命周期和 ACL 尚未实机验证；Linux 桌面保留切换暂不支持。合成恢复及预览结果不等同于真实桌面完整验收，也不证明已无正文的会话可以恢复。已有 Rust 未使用代码警告及 Vite chunk 大小提示未作为本功能修改内容。
